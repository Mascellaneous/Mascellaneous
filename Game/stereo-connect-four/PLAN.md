# Game Plan：立體過四關

## 風險任務

### 1. 4×4×4 的勝利線產生與判定

- **為何要隔離：** 三維棋盤共有 76 條可連成四子的勝利線；手寫枚舉容易遺漏空間對角線或重複計算。
- **方法：** 以 13 個正規化方向向量為基礎，掃描每一格，只保留「前一格不在盤內」的線段起點，產生恰好長度為 4 的不重複座標序列。每次落子後只從最近落子對應的候選線判斷。
- **驗證：** 分別建立 X、Y、Z 軸直線、XY/XZ/YZ 平面對角線、XYZ 體對角線的局面；每種情況皆必須標出剛好四枚棋子並結束該局。

### 2. 電腦對手的策略優先順序

- **為何要隔離：** AI 必須可玩且快速，不能在「阻擋一手必勝」與「尋找自身一手必勝」的優先順序上出錯。
- **方法：** 不使用深度搜尋；依序檢查 AI 即勝、玩家即勝、中心權重、形成可延伸二連線、隨機平手破局。困難模式再以候選格的勝利線潛力加權。
- **驗證：** 對於 AI 與玩家都各自差一子就能連四的局面，AI 必須優先完成自身勝利；只存在玩家必勝威脅時，AI 必須落子阻擋。

## 主要建置

- 一個可直接離線開啟的 `index.html`，把 CSS、SVG、JavaScript 內嵌在同一檔案，完全不載入第三方套件、字體或網路資源。
- 可互動的 4×4×4 等角棋盤；玩家可透過棋盤直接落子，並以樓層切換、半透明層級與座標標記閱讀 Z 軸。
- 本機雙人、對電腦（輕鬆／戰術）兩種模式，回合提示、重新開始、悔棋、規則視窗、音效切換、棋盤視角與動畫設定。
- 使用 CSS 製作玻璃狀棋子、棋盤網格、光帶勝利線與小型 SVG 介面圖示，毋須額外素材才可玩。
- 提供 `?demo` 自動示範參數，讓螢幕截圖可呈現真實對局狀態。

- **素材需求：** 遊戲主程式不依賴圖片；開發專案的視覺 QA 使用「晶格指揮中心」概念主視覺、深色格網背景、無文字幾何標誌與低對比材質作為參考。
- **驗證：**
  - 觸控、滑鼠與鍵盤操作均可選擇空格，已佔用位置不可重複落子。
  - 樓層與座標標示清楚，四個平面不會遮蔽可點擊區域。
  - 所有模式均能正確換手、結束、重新開始與悔棋；AI 回合不接受玩家落子。
  - 可讀的鍵盤焦點、ARIA 標籤、高對比提示與減少動態效果設定。
  - 小螢幕直向捲動時不溢位，按鈕具足夠觸控面積。
  - 無外部網路請求；可用雙擊本機 `index.html` 遊玩。
  - 視覺與參考一致：深藍灰指揮台、訊號青綠／珊瑚橘對弈色、精密而克制的空間網格。
  - 擷取期間沒有瀏覽器主控台錯誤。
