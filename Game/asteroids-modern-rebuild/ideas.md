# Asteroids Modern Remake：設計方向

## 三種可能方向

### 方向 A：陰極射線星圖

**Very Brief Intro：** 以早期向量街機與陰極射線管為靈感，讓低飽和磷光線條、微量掃描紋與克制的發光共同營造精準、孤絕的太空操作感。這個方向把「舊遊戲」的輪廓轉為高可讀性的當代介面。

**Probability：** 0.04

### 方向 B：航電儀表手冊

**Very Brief Intro：** 採用深色任務控制台與航空儀錶手冊的層次，強調航線、動力與威脅讀數，讓每個遊戲狀態都有可見的功能理由。情緒更偏向冷靜的駕駛艙，而非街機櫃。

**Probability：** 0.07

### 方向 C：太空印刷海報

**Very Brief Intro：** 以 1970 年代科幻平面海報的顆粒、強烈留白與切角排版重構遊戲，讓宇宙不是漆黑空洞，而是帶有印刷紙材感的舞台。這個方向特別適合把分數與波次轉化為主視覺元素。

**Probability：** 0.03

## 選定方向：陰極射線星圖

### Design Movement

本作採用**向量街機復興（Vector Arcade Revival）**與**陰極射線顯示器（CRT）**的當代詮釋。畫面不是擬真 8-bit 濾鏡，而是以細、亮、可辨識的幾何線條呈現速度與慣性，保留經典 Asteroids 的抽象物件語言。

### Core Principles

1. 以**幾何輪廓**而非貼圖敘事，所有遊戲物件都必須可在高速移動中辨認。
2. HUD 是駕駛艙工具而非裝飾；讀分、生命、波次與控制提示都應靠近玩家視線邊界。
3. 光暈僅用於強調能量、危險與操作回饋，避免用泛濫的霓虹遮蔽資訊結構。
4. 每一個顯示效果都從遊戲狀態出發：推進、擊發、破碎與重生要有可感知的視覺回應。

### Color Philosophy

主要畫面以近黑藍（`#060B12`）建立無限星空，並將柔和磷光青綠（`#A5FFD6`）視為船體、瞄準與正向操作的共通語言。琥珀橘（`#FFC857`）只用於推進與動能，危險紅（`#FF5D73`）只用於生命損失、爆炸或警示。這是具功能性的色彩分工，而非裝飾性配色。

### Layout Paradigm

畫面採用**環繞式駕駛艙框架**：遊戲畫布佔據視窗的重心，分數、生命與波次不擠進中央欄位，而是沿著上緣與側下角構成讀數軌道。開始與暫停面板停駐在畫布中央但刻意保留足夠空域，讓玩家先感受場域再讀文字。

### Signature Elements

1. 細微的掃描線與 CRT 邊緣暗角，讓平面畫面具有老式顯示器的物理感。
2. 左上角「ASTR // 79」的壓縮標記與象徵小行星、飛船、訊號的三段式幾何識別。
3. 子彈尾跡、引擎粒子與碎石火花使用短暫且收斂的磷光殘影，避免厚重模糊。

### Interaction Philosophy

鍵盤操作必須立即反映在姿態、推進與能量軌跡上。玩家按下控制鍵時不等待裝飾性動畫；開始、重啟與暫停則使用短促的訊號鎖定回應，以突顯飛行狀態切換。

### Animation

主迴圈以 `requestAnimationFrame` 驅動，並以時間差校正各種移動速度。粒子淡出、標題呼吸與面板出現只使用透明度與位移，不使用長時間的縮放。一般 UI 的轉場維持在 120–220ms，且在 `prefers-reduced-motion` 下移除非必要的介面動畫；遊戲內物理與輸入回饋不受影響。

### Typography System

主要標題使用系統可取得的等寬字型堆疊（`"Courier New", Courier, monospace`）並以大字距、全大寫建立儀器刻度感；說明與 HUD 使用同一堆疊的較小字級，避免額外網路字型相依。字級層級是：主標 24–36px、狀態讀數 12–16px、控制文字 10–12px。

### Brand Essence

**以當代瀏覽器重新演繹向量小行星戰鬥，為重視手感與可讀性的經典街機玩家而設。**

人格：**精準、孤絕、敏捷**。

### Brand Voice

標題與操作文案像任務指令，簡短、具體、沒有空泛口號；CTA 以動詞和遊戲狀態開頭。

> 「訊號鎖定。清空軌道。」

> 「按 ENTER 部署攔截艇。」

### Wordmark & Logo

字標以 `ASTR // 79` 表示，雙斜線象徵瞄準校準與斷裂隕石軌跡。圖形標誌是不含文字的三角形飛船、弧形軌道與一塊不規則小行星組成的極簡磷光符號。

### Signature Brand Color

本作的識別色為**軌道磷光綠 `#A5FFD6`**；它只在可互動物件與關鍵讀數上出現，以維持辨識度。
