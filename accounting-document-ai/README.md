# 會計文件 AI 問答

這是一套以登入保護的文件知識庫問答工具。管理員可將會計相關文件上傳至「文件管理」，系統會抽取文字、切分為可檢索段落，讓使用者從「知識問答」以自然語言查詢。每個回答均會顯示實際使用的文件段落來源，方便核對與追溯。

## 日常使用

| 身份 | 操作方式 |
| --- | --- |
| 管理員 | 登入後進入「文件管理」，選擇 PDF、Word（`.docx`）或 TXT 檔案。系統會即時顯示「處理中」，完成後標示「已就緒」與可檢索段落數。 |
| 一般使用者 | 登入後開啟「知識問答」，輸入問題並送出。回答下方的「引用來源」可展開查看所用文件與段落摘要。 |
| 所有使用者 | 左側「歷史紀錄」會保留自己的舊對話；點選任一紀錄即可重新查看。 |

每份文件上限為 **12 MB**。請優先使用具可選取文字的 PDF；掃描影像型 PDF 若沒有文字層，系統無法可靠地抽取內容。舊式 Word `.doc` 格式請先在 Microsoft Word 另存為 `.docx` 後再上傳。

## 問答原則

系統先從已完成解析的文件段落中找出候選內容，依問題的語意重新排序，再將最相關段落交給 AI 撰寫答案。AI 被明確限制只能引用這些段落；若來源不足，會回覆「文件庫未包含足夠資訊以回答此問題」，而不會以外部知識補充。

## 發布步驟

此專案已採用受代管的網頁服務，不需要自行設定伺服器。當你準備好讓其他人使用時，請先建立一個專案版本，然後在管理介面的右上角按 **Publish**。之後可依需要設定網站名稱、可見性與自訂網域。

## 已實作的保護措施

原始文件存放於受管理的檔案儲存空間，資料庫只儲存檔案索引、解析後段落、問答紀錄及引用資料。文件上傳頁僅對管理員開放；問答歷史僅限建立該紀錄的登入使用者查閱。
