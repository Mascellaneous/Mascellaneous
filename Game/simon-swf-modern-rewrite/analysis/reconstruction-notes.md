# SWF 行為還原筆記

> 本文件基於 `simon.swf` 的靜態標籤、內嵌字串、音效與 AVM1 指令檢視而成；未啟動或執行 SWF。

## 證據摘要

| 原始元素 | 靜態證據 | 現代實作決策 |
|---|---|---|
| Flash 格式 | CWS、Flash 6、21 FPS、64 個主時間軸影格 | 不保留時間軸；改用 JavaScript 明確狀態機與 `await` 延遲。 |
| 四色操作盤 | `green_btn`、`yellow_btn`、`blue_btn`、`red_btn`，且四個 `onPress` 分別傳入 `0` 至 `3` | 四個語意化 `<button>`，以資料屬性管理顏色與鍵盤映射。 |
| 序列資料 | `seq_array`、`tempSeq_array`、`Math.random`、`push`、`slice`、`shift` | `sequence` 保存正解；`expected` 保存玩家尚待輸入的副本。 |
| 回合旗標 | `compTurn` 與 `enabled` | `phase` 取代布林組合：`idle`、`computer`、`player`、`lost`。 |
| 分數與高分 | `score`、`highScore`、`SharedObject.getLocal('neaveSimon')`、`game_so.data.score` | `score` 為目前已完成回合數；`localStorage` 保存最高分。 |
| 音效 | 六個 `DefineSound`，皆為原 SWF 內嵌 MP3；其中四個為約 0.42–0.52 秒的明確單音 | 原始 MP3 轉為 Base64 data URI 內嵌，讓成品仍是單一 HTML 檔且離線可用。 |
| 難度節奏 | 主時間軸於分數 4、9、14、19 後跳至不同段落 | 每五回合加快訊號間距，並設定下限，保留階段性加速的體驗。 |

## 推導出的回合流程

1. 玩家按下開始後，清空分數並建立第一個隨機顏色。
2. 電腦鎖定輸入，依序亮起並播放每一個既有顏色。
3. 電腦播放結束後，複製完整序列至玩家佇列並解鎖四個按鍵。
4. 每次玩家輸入會與佇列第一個顏色比對；正確時移除該元素，並提供色光與聲音回饋。
5. 若玩家完成佇列，分數加一，視需要更新最高分，新增一個隨機顏色後重回電腦播放。
6. 若玩家輸入錯誤，立刻鎖定輸入、播放失敗提示、顯示本回合分數，並等待重新開始。

## 現代化邊界

原版使用 ActionScript 2 事件屬性（例如 `onPress`、`onRelease`）與影格標籤控制。重製版不模擬 Flash Player，亦不複製原版的外站連結或過時預載器；而是保留遊戲核心、音效資產、高分概念與難度階梯，並補上可見焦點、按鈕名稱、鍵盤可玩性與減少動畫偏好。

## 按鍵映射

使用數字列與方向鍵做成一致、可記憶的現代映射：`1`/`↑` 為綠色、`2`/`→` 為紅色、`3`/`↓` 為藍色、`4`/`←` 為黃色。這是為改善可近用性而採用的重製選擇，並非聲稱為原 SWF 的精確熱鍵組合。
