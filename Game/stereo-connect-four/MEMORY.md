# Memory：立體過四關

## 已完成內容

根目錄的 `index.html` 是唯一正式交付物，完全內嵌樣式、SVG 與 JavaScript，並已掃描確認未載入外部網路資源。它實作 4×4×4 棋盤、76 條動態產生的勝利線、對戰電腦／同機雙人、兩種 AI 強度、樓層聚焦、悔棋、分數、音效、動態效果偏好、鍵盤操作與 `?demo`。

## 已驗證內容

`node scripts/verify-game.mjs` 會確認 76 條唯一勝利線及其判定。`pnpm check` 與 `pnpm build` 均已通過；預覽主控台沒有錯誤或警告紀錄。已檢視桌面與 375px 寬度的預覽；視覺審查確認「晶格指揮中心」風格一致。

## 保留的設計決策

生成的主視覺、標誌與材質只服務於 WebDev 預覽殼層及視覺 QA；為符合可離線開啟的使用者需求，根目錄單檔版本不載入那些影像。單檔版本使用 CSS、內嵌 SVG 和資料 URI 來替代外部視覺依賴。

AI 不採完整 Minimax 搜尋，而是依即勝、阻擋、中心偏好和可延伸路徑評分排序。這個選擇讓 64 格棋盤仍有直接的回應時間與可理解的難度設定。
