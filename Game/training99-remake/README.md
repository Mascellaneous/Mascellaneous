# 特訓99｜零依賴網頁重製版

> 直接以瀏覽器開啟 `index.html` 即可遊玩。此資料夾不需要 Node.js、npm、套件安裝、建置工具、CDN、伺服器或網路連線。

這是以 HTML、CSS、JavaScript 與 Canvas 2D 製作的《特訓99》現代網頁重製版。玩法保留小飛機在黑色戰場中躲避火球、以生存時間為主要成績的短回合反應核心。公開玩家心得記錄原作使用 Enter 和四方向鍵，並呈現生存時間、活動時間、彈數及「絕妙度」。[1] 本版另支援 WASD 與觸控方向鍵，對應後續網頁重製所採用的桌面操作方式。[2]

## 執行方式

請解壓縮後直接雙擊 `index.html`，或以任何現代瀏覽器的「開啟檔案」功能載入它。遊戲使用瀏覽器內建的 `localStorage` 儲存設定和最佳成績；若本機檔案模式不允許儲存，遊戲仍可正常進行，只是不會保留紀錄。

> **Chrome 的 file:// 相容性：** 發布版載入的是傳統的單一腳本 `js/game.js`，沒有使用 ES Module 的 `type="module"`、`import` 或動態載入。因此直接從 Windows 檔案總管開啟時，不會觸發 ES Module 的 `origin null` CORS 限制。

已使用 Chromium 以 `file://` 直接開啟本資料夾的 `index.html` 驗證：起始畫面可正常呈現，按下「開始特訓」後會進入倒數並出現玩家機，表示傳統腳本已成功載入與執行。

```text
standalone/
├── index.html        # 直接開啟此檔案
├── styles.css        # 視覺與響應式排版
├── js/
│   └── game.js       # 發布用單一傳統腳本；可直接被 file:// 載入
├── src/              # 維護用小型來源檔；不會被網頁直接載入
│   ├── config.js     # 難度、設定、亂數與 localStorage
│   ├── input.js      # 鍵盤與觸控輸入
│   ├── renderer.js   # Canvas 繪製
│   └── game.js       # 模擬、碰撞、計時與結算
├── tools/
│   └── bundle-classic.mjs # 只使用 Node.js 內建模組的發布檔重建工具
└── README.md
```

## 操作

| 動作 | 鍵盤 | 觸控 |
| --- | --- | --- |
| 移動 | 方向鍵或 `W`、`A`、`S`、`D` | 畫面下方四向按鈕 |
| 開始／再試一次 | `Enter` 或 `Space` | 開始／再來一次按鈕 |
| 音效 | 設定區的「回饋音效」開關 | 同左 |

## 遊戲規則與可調設定

玩家在黑色戰場中操作小飛機，避開一般火球與有限追尾彈。每回合的生存時間是主要紀錄；彈幕會隨時間提高生成密度與速度。玩家可調整難度、生命數、飛行手感與音效，所有選項均會在下一回合套用。

| 設定 | 選項 | 作用 |
| --- | --- | --- |
| 威脅密度 | 校準、標準、高壓、極限 | 同時改變安全窗、生成間隔、彈速、追尾能力與畫面彈數上限。 |
| 容錯生命 | 1、3、5 格 | 決定單回合可承受碰撞次數；預設 1 格保留原版式單局壓力。 |
| 飛行手感 | 直接反應、慣性滑行 | 直接反應適合精準修正；慣性滑行保留加速與阻尼。 |
| 回饋音效 | 開／關 | 首次玩家操作後才初始化瀏覽器內建音訊。 |

HUD 中的 `THREATS` 是生成彈數；`CLOSE CALL` 為絕妙度。火球進入近距離環但沒有撞到飛機時，會依距離增加 1–3 點，且同一顆彈只會計算一次。發生碰撞時，扣除生命與短暫無敵的判定永遠優先。

## 程式架構

遊戲的核心不是依賴每幀不固定的畫面時間，而是以 `requestAnimationFrame` 累積時間後，按固定 60Hz 步長更新。單幀時間差最多採計 50ms，以避免切換分頁後發生彈體跨越畫面或漏掉碰撞。Canvas 只負責根據世界狀態繪製；輸入、生成、碰撞與成績分別集中於獨立模組。

| 檔案 | 職責 |
| --- | --- |
| `js/game.js` | 發布版唯一載入的傳統腳本，依序合併以下四個來源；不包含 ES Module 指令。 |
| `src/config.js` | 定義四種難度曲線、預設設定、固定種子亂數、時間格式與本機儲存。 |
| `src/input.js` | 將鍵盤／觸控統一對映到 `up`、`down`、`left`、`right`、`start`。 |
| `src/renderer.js` | 繪製星點、邊界、玩家機、火球、倒數、擦彈回饋及受擊閃光。 |
| `src/game.js` | 管理 `idle → countdown → playing → ended` 狀態、固定步長模擬、碰撞、結算與可選音效。 |

如要調整節奏，請先改 `src/config.js` 的 `DIFFICULTIES`；如要調整飛機移動，再改 `src/game.js` 的 `updatePlayer()`。修改後在本資料夾內執行以下命令以更新 `js/game.js`。這個重建工具只引用 Node.js 內建模組，不需要安裝 npm 套件；玩家直接開啟遊戲時不需要 Node.js。

```bash
node tools/bundle-classic.mjs .
```

不要直接編輯發布檔，才能確保來源與實際交付版保持一致。

## 原作研究與美術來源

使用者提供的 EXE 先以靜態方式分析：其中唯一可直接重建的視覺資產是 32×32 的原始程式圖示，已內嵌到 `index.html`。原始檔案的靜態資源中沒有可匯出的飛機、火球或背景點陣圖，因此本版的戰場元素採 Canvas 幾何／像素式重新繪製，而不會不實宣稱它們直接擷取自 EXE。

在使用者後續明確授權下，也曾於獨立使用者、暫存 32 位元相容前綴、無網路命名空間與虛擬畫面中受限執行原始 EXE。相容環境僅顯示亂碼警示對話框，關閉後沒有可可信辨識的戰場畫面；因此本發布版沒有根據該黑畫面推測或臆造新的規則。

## 零依賴聲明

此發布資料夾沒有執行期第三方依賴。它只使用瀏覽器內建的 Canvas 2D、Web Audio（可選）與 localStorage。沒有 npm 套件、無 `<script>` CDN、無遠端圖片、無遠端字體、無分析服務、無 API 請求。

發布版可用下列指令做語法檢查；遊戲本身不需要執行它們。

```bash
node --check js/game.js
```
