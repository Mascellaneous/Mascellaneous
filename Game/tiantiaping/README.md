## 遊戲簡介

《天下太平》是一款以「猜拳」為核心機制的策略型小遊戲。玩家與電腦輪流出拳，猜拳勝者可選擇「建設」累積資源，或消耗資源發動「攻擊」削減對手 HP。雙方各有 10 點 HP，率先將對手 HP 歸零者獲勝。

遊戲畫面以太空俯瞰地球為背景，紅藍雙方的建設格分別排列在畫面上下方，HP 條顯示於中央，簡潔而直觀。

## 如何遊玩

### 直接開啟

下載或複製本專案後，直接用瀏覽器開啟 `index.html` 即可，**無需任何伺服器或安裝步驟**。

```
雙擊 index.html → 在瀏覽器中開啟
```

### 本地伺服器（選用）

若需要透過 HTTP 伺服器提供服務：

```bash
# Python 3
python3 -m http.server 8080

# Node.js（需安裝 npx）
npx serve .
```

## 遊戲規則詳解

### 基本流程

每一回合分為兩個階段：**猜拳階段**與**行動階段**。

**猜拳階段**：玩家從布、剪刀、石頭三種手勢中選擇一種，電腦同時隨機出拳，依標準猜拳規則判定勝負：

| 玩家出拳 | 電腦出拳 | 結果 |
|----------|----------|------|
| 布 | 石頭 | 玩家勝 |
| 剪刀 | 布 | 玩家勝 |
| 石頭 | 剪刀 | 玩家勝 |
| 相同 | 相同 | 平手（重新猜拳） |
| 其他 | 其他 | 玩家敗 |

**行動階段**：

- **猜拳勝者**可選擇以下兩種行動之一：
  - **建設**：在己方建設格中增加 1 格（最多 10 格）
  - **攻擊**：消耗 7 格建設，使對方 HP 減少 1 點
- **猜拳敗者**：由電腦 AI 自動執行行動（建設或攻擊）
- **平手**：雙方均不行動，直接進行下一回合猜拳

### 勝負條件

任一方 HP 歸零即告失敗。若雙方同時 HP 歸零，則為平局。

### 攻擊限制

攻擊需消耗 **7 格建設**，因此在建設格不足 7 格時，攻擊按鈕將呈現禁用狀態。這一設計迫使玩家在「快速積累建設」與「及時發動攻擊」之間做出策略取捨。

### 電腦 AI 策略

電腦在猜拳獲勝後，若建設格達到 7 格以上，有 60% 機率選擇攻擊，否則選擇建設。這一設計保留了原作的 AI 行為模式，同時提供適當的挑戰難度。

## 技術說明

### 前端架構

本重製版採用純 HTML5 + CSS3 + Vanilla JavaScript，**不依賴任何外部函式庫或框架**，可在任何支援 ES6 的現代瀏覽器中直接執行。

| 技術 | 用途 |
|------|------|
| HTML5 Canvas | 手勢圖示繪製、太空背景程序化生成 |
| CSS3 動畫 | 場景切換、按鈕互動、結果浮層效果 |
| Web Audio API | 全部音效（無需外部音效檔案） |
| CSS clip-path | START 按鈕的六角形造型 |
| CSS Grid | 建設格排列 |

### 音效系統

所有音效均透過 **Web Audio API** 即時合成，不依賴任何外部音效檔案：

| 音效 | 觸發時機 | 波形 |
|------|----------|------|
| 點擊音 | 按鈕點擊 | 方波 |
| 勝利音 | 猜拳獲勝 | 三角波上行音階 |
| 失敗音 | 猜拳落敗 | 鋸齒波下行音階 |
| 平手音 | 猜拳平手 | 正弦波雙擊 |
| 建設音 | 建設行動 | 三角波上行 |
| 攻擊音 | 攻擊行動 | 鋸齒波低頻 |
| 勝利樂 | 遊戲獲勝 | 三角波旋律 |
| 失敗樂 | 遊戲落敗 | 鋸齒波旋律 |

### 背景繪製

對戰場景的太空俯瞰地球背景以 Canvas 2D API 程序化繪製，忠實還原原作的視覺風格：深黑太空、星點、地球弧線、大氣層光暈、陸地輪廓與雲層。

## 逆向工程過程

### 工具與方法

本重製版透過以下步驟完成逆向工程：

1. **格式識別**：確認原始檔案為 SWF 版本 5，未壓縮格式
2. **XML 轉換**：使用 `swfmill` 將 SWF 轉換為 XML，完整保留所有標籤資訊
3. **資產匯出**：解析 `DefineBits` 標籤，匯出 4 張內嵌 JPEG 圖片
4. **邏輯還原**：逐一分析 57 個 `DoAction` 區塊的 ActionScript 位元組碼，還原遊戲狀態機
5. **視覺比對**：使用 Ruffle（Flash 相容播放器）執行原作，擷取各場景截圖作為比對依據

### 關鍵發現

透過分析 ActionScript 位元組碼，還原了以下核心邏輯：

- **HP 系統**：`myhp`（玩家）與 `yourhp`（電腦）各初始化為 10
- **建設格**：`B1`–`B10`（玩家）與 `R1`–`R10`（電腦）各 10 個 Sprite 物件
- **攻擊條件**：`myhp >= 7`（原作 Button 100 的條件判斷）
- **電腦出拳**：`Random(3)` 隨機選擇 0、1、2 對應三種手勢
- **場景結構**：63 個影格的主時間軸，含標題、猜拳、對戰、勝負四個主要場景
