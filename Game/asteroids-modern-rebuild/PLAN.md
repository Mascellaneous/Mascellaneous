# Game Plan: Asteroids Modern Remake

本計畫以使用者提供的 `original/asteroids.swf` 為逆向分析對象，重製其核心的轉向、推進、射擊、小行星分裂、飛碟、生命與分數循環。最終交付為一個可離線開啟的 `asteroids-modern.html`，不使用第三方函式庫、字型或網路請求。

## Risk Tasks

### 1. 時間校正的環繞式慣性飛行

- **Why isolated:** 傳統 Flash 遊戲通常讓每幀邏輯與固定幀率耦合；搬到瀏覽器後，螢幕刷新率與分頁節流會讓速度與操控感不一致。
- **Approach:** 以 `requestAnimationFrame` 的實際時間差為唯一更新尺度，將每一個速度常數以秒為單位計算，並限制單次更新的最大時間差。位置通過邊界後從另一側回到舞台，以物件半徑補償視覺跳變。
- **Verify:** 以不同視窗大小連續按住推進 3 秒，飛船方向、加速與跨邊界位置都連續；暫停後恢復不會產生瞬移或暴衝。

### 2. 多尺度小行星分裂與環面碰撞

- **Why isolated:** 遊戲場域是環面；單純的平面圓碰撞會漏判螢幕左右或上下邊緣相鄰物件，且分裂時必須避免母體與子體重疊造成連鎖誤擊。
- **Approach:** 小行星以可重現的多邊形輪廓和包圍圓表示。碰撞同時測量本體與橫向、縱向各一個場域尺寸的最短距離；大型與中型小行星命中後，生成兩個反向旋轉、帶隨機但受限速度的子體。
- **Verify:** 在任一邊界附近射擊小行星時都能命中；大型會拆成兩個中型，中型會拆成兩個小型，小型才移除；每次命中只增加一次分數。

### 3. 使用者手勢後的原始音效解鎖

- **Why isolated:** 瀏覽器禁止在沒有手勢時自動播放音效，而原作是 Flash 時間軸與 `Sound.attachSound` 的即時播放模型。
- **Approach:** 將已抽取的原始 MP3 以 Base64 `data:` URL 內嵌，首個 ENTER、按鍵或按鈕事件才建立音效複本並將 `audioUnlocked` 設為真。高頻事件採小型複本池，避免同一 HTMLAudioElement 被反覆中斷。
- **Verify:** 未開始前不播放聲音；按 ENTER 或點選開始後，推進、飛碟、節拍與爆炸都可播放，且連續命中不會讓瀏覽器拋出未處理的播放拒絕錯誤。

## Main Build

遊戲畫面採滿視窗 Canvas，並以 Canvas 2D 畫出向量飛船、隕石、子彈、粒子、星空與 HUD。模式機維護 `title`、`playing`、`paused`、`respawning` 與 `gameover`；輸入層把多組實體鍵映射為 `turnLeft`、`turnRight`、`thrust`、`fire`、`hyperspace`、`pause` 與 `start`。敵對飛碟在波次進度足夠時隨機進入場域，並發射速度較慢、可被玩家攔截的子彈。

- **Assets:**
  - 原始 `thrust`、`saucerSmall`、`saucerBig`、`beat1`、`beat2` MP3，內嵌於單檔，分別供推進、飛碟與節拍事件使用。
  - 生成的低干擾星空質地，以內嵌 Data URL 作為遊戲畫布背景層。
  - 生成的圖形標誌，用於標題介面與無障礙替代文字周邊，不影響核心碰撞圖形。
- **Verify:**
  - 箭頭鍵與 WASD 能轉向及推進；SPACE 能射擊；H 能執行可控風險的超空間跳躍；P 或 ESC 能暫停。
  - 子彈遵守最大同時數量與生命週期；飛船、小行星、飛碟、子彈皆可跨邊界。
  - 分數、生命、波次、暫停及重生狀態的 HUD 可讀且不與畫面邊界重疊。
  - 沒有遠端函式庫、分析碼、網路字型或資產請求；離線開啟 `asteroids-modern.html` 仍能遊玩。
  - Console 沒有錯誤；`?demo=1` 會自動開始並提供可截圖的活動遊戲畫面。
  - 參考圖的一致性：近黑藍背景、磷光綠向量輪廓、琥珀推進、稀疏星點與環繞式 HUD。
